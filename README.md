Retail Sales Analysis Project

Project Overview

This project is part of my Data Analytics Internship. It includes practical tasks completed from Day 21 to Day 29, focusing on retail sales data analysis, data cleaning, Python, SQL, and KPI development.

Project Objectives

- Understand business requirements and datasets.
- Perform data cleaning and preprocessing.
- Analyze retail sales data using Python.
- Write SQL queries to extract meaningful insights.
- Calculate key performance indicators (KPIs).
- Prepare organized documentation and reports.

Dataset

The dataset contains retail sales information, including orders, customers, products, sales, profit, quantity, category, and region.
